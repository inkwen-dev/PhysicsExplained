## 任务清单格式说明

每个任务清单包含以下信息：

### 基础数据字段

- **序号**：选题编号（1-100）
- **标题**：文章标题（英文）
- **Slug**：URL slug（小写，连字符分隔）
- **子分类**：子分类ID（用于文件路径）
- **关键词**：SEO关键词
- **搜索意图**：信息型（why/how/what is/what are/difference）
- **难度**：⭐⭐（简单）或 ⭐⭐⭐（中等）
- **状态**：✅ 已完成 或 ⬜ 待完成
- **发布日期**：2025年11月、12月，2026年1月（随机分配）

### 文件路径规范

所有文章应保存在：`content/topics/{category}/{subcategory}/{slug}.md`

示例：
- `content/topics/classical-mechanics/kinematics/why-do-objects-fall.md`
- `content/topics/electromagnetism/electrostatics/what-is-electricity.md`
