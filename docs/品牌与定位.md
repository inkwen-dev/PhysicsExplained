# 品牌与定位

> **域名**：PhysicsExplained.org  
> **品牌名**：Physics Explained

---

## 一、品牌定位

### 1.1 品牌核心价值

**PhysicsExplained.org** 是一个物理科学科普网站，核心定位：

- **深入浅出**：用简单语言解释复杂的物理概念
- **科学准确**：基于物理原理和科学依据
- **实用价值**：不只是解释，还要提供实际应用和实验
- **SEO友好**：符合搜索引擎优化要求

### 1.2 目标用户

- 对物理科学感兴趣的用户
- 想理解物理现象的学生
- 想回答孩子问题的家长
- 教育工作者和普通用户

### 1.3 品牌调性

- **专业但易懂**：不是学术论文，但要有科学依据
- **友好但权威**：不是娱乐内容，但要有亲和力
- **深入但实用**：不只是理论，还要有实际应用和实验

## 二、网站定位

### 2.1 网站定位

**PhysicsExplained.org** 是一个物理科学科普网站，用简单语言解释复杂的物理现象和原理，基于物理科学原理。

### 2.2 内容定位

- **问答形式**：以问题为导向，直接回答用户疑问
- **科学依据**：所有解释基于物理原理和科学依据
- **实用导向**：提供可操作的应用和实验演示
- **结构清晰**：Short Answer + Detailed Explanation + Practical Applications

### 2.3 差异化优势

- **深入浅出**：复杂概念用简单语言解释
- **系统化**：6个主分类，24个子分类，内容组织清晰
- **可扩展**：支持扩展到1500+篇文章
- **SEO优化**：每个问题都是独立的长尾关键词
