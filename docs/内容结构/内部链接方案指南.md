# 内部链接方案指南

> **最终方案**：手动正文链接 + Frontmatter底部推荐  
> **目标规模**：100-1500篇文章  
> **最后更新**：2024年

---

## 一、最终采用的方案

### 1.1 核心策略

采用**混合方案**，平衡链接质量和维护效率：

- **正文内部链接**：手动添加，使用标准 Markdown 语法（高质量、自然）
- **底部推荐**：Frontmatter 的 `relatedTopics` 字段自动渲染（标准化）

### 1.2 方案优势

- ✅ **链接质量高**：手动添加确保相关性和自然度
- ✅ **维护简单**：使用标准 Markdown，无需额外技术实现
- ✅ **SEO友好**：符合搜索引擎最佳实践（每1000字2-5个链接）
- ✅ **用户体验好**：链接自然融入内容，不干扰阅读

## 二、内容编辑指南

### 2.1 如何添加正文内部链接

#### Markdown 格式

在正文中自然插入内部链接，使用标准 Markdown 链接语法：

```markdown
## Scientific Principles

Gravity is related to [How does gravity work?](how-does-gravity-work) and other fundamental forces.

Research shows that [Why do objects fall?](why-do-objects-fall) is crucial for understanding motion.
```

#### 链接格式说明

- **格式**：`[文章标题](article-slug)`
- **文章标题**：使用完整的文章标题（英文）
- **article-slug**：目标文章的 slug（小写，连字符分隔）

### 2.2 链接添加规范

#### 链接位置

- ✅ **推荐**：自然融入句子中间
- ✅ **推荐**：在 Background 或 Scientific Principles 部分
- ❌ **避免**：在段落开头放置链接
- ❌ **避免**：连续多个链接

#### 链接数量

- **每1000字**：2-5个内部链接
- **每段**：不超过1-2个链接
- **避免过度链接**：保持阅读流畅性

#### 锚文本规范

- ✅ **使用完整文章标题**：`[How does gravity work?](how-does-gravity-work)`
- ✅ **自然融入上下文**：链接文本应该自然融入句子
- ❌ **避免**：使用"点击这里"、"了解更多"等通用文本

### 2.3 链接相关性要求

- ✅ **高度相关**：只链接与当前内容真正相关的文章
- ✅ **上下文自然**：链接应该自然出现在讨论相关概念的地方
- ❌ **避免**：为了SEO而添加不相关链接

## 三、底部推荐设置

### 3.1 Frontmatter 配置

在文章的 Frontmatter 中设置 `relatedTopics` 字段：

```yaml
---
title: "Why do objects fall?"
slug: "why-do-objects-fall"
relatedTopics:
  - "how-does-gravity-work"
  - "what-is-velocity"
  - "what-is-acceleration"
---
```

### 3.2 推荐数量

- **每篇文章**：3-8个相关主题
- **优先使用**：Frontmatter 中的 `relatedTopics` 字段
- **自动过滤**：系统会自动排除已在正文中链接的文章

### 3.3 推荐原则

- ✅ **强相关性**：选择与当前文章主题高度相关的文章
- ✅ **互补内容**：选择能补充或扩展当前内容的文章
- ✅ **用户价值**：选择用户可能感兴趣的相关内容

## 四、技术实现要点

### 4.1 正文链接

- **实现方式**：使用标准 Markdown 渲染，无需额外处理
- **样式**：系统自动应用内部链接样式（主题色、悬停效果）
- **验证**：链接有效性通过构建时验证

### 4.2 底部推荐

- **数据源**：从 Frontmatter 的 `relatedTopics` 字段读取
- **渲染位置**：文章底部，卡片式布局
- **显示内容**：文章标题和简短摘要

### 4.3 链接验证

- **构建时检查**：所有内部链接在构建时验证有效性
- **断链检测**：自动检测并报告无效链接
- **维护建议**：定期运行验证脚本检查链接有效性

## 五、编辑提示词模板

### 5.1 添加内部链接的提示词

```
在以下位置为文章添加2-3个内部链接：
- Background 部分：1个链接
- Scientific Principles 部分：1-2个链接

要求：
1. 使用完整文章标题作为锚文本
2. 自然融入句子，不打断阅读
3. 只链接高度相关的内容
4. 使用格式：[文章标题](article-slug)

示例：
Understanding [How does gravity work?](how-does-gravity-work) helps explain this phenomenon.
```

### 5.2 设置相关主题的提示词

```
为文章设置3-5个相关主题（relatedTopics）：
- 选择与当前主题高度相关的文章
- 优先选择互补或扩展性的内容
- 使用文章的slug（小写，连字符分隔）

示例：
relatedTopics:
  - "how-does-gravity-work"
  - "what-is-velocity"
  - "what-is-acceleration"
```

## 六、最佳实践总结

### 6.1 链接策略

- **正文链接**：高质量、自然、相关
- **底部推荐**：标准化、全面、互补
- **避免过度链接**：保持阅读体验优先

### 6.2 维护建议

- **新文章发布时**：立即添加2-3个正文内部链接
- **定期审查**：每季度检查链接有效性和相关性
- **根据数据优化**：根据用户访问数据优化链接策略
